# V0.5 — Selectivity + medicinal-chemistry evidence

V0.5 asks two questions that the activity/ADMET stack cannot answer alone:

1. **Is the candidate chemically suspicious, derivative or unusually complex?**
2. **Could the candidate plausibly inhibit other kinases rather than LRRK2 selectively?**

Neither layer is treated as experimental truth. The goal is to expose reasons to investigate or reject a hypothesis before anyone spends laboratory money.

## Medicinal-chemistry evidence

`pdl medchem-annotate` adds:

- RDKit **PAINS**, **BRENK**, **NIH** and **ZINC** filter-catalog matches;
- RDKit **QED** as a descriptive drug-likeness metric;
- Bertz complexity, heavy-atom count, ring count and stereo-centre count;
- a transparent bounded **synthetic-complexity proxy** (not a retrosynthesis model or validated synthetic-accessibility score);
- nearest-known chemistry using Morgan radius-2 / 2048-bit Tanimoto similarity;
- `novelty_proxy = 1 - nearest_similarity`;
- explicit review flags rather than automatic chemistry rejection.

RDKit's current FilterCatalog API includes PAINS, BRENK, NIH and ZINC catalogs. QED is an aggregate descriptor built from common molecular properties. These are triage tools; they do not prove toxicity, novelty, assay interference or developability.

```bash
pdl medchem-annotate \
  --input artifacts/lrrk2/candidates_admet.csv \
  --reference data/snapshots/lrrk2/cleaned_molecules.csv \
  --out artifacts/lrrk2/candidates_medchem.csv
```

## Selectivity evidence

Kinase inhibitors need selectivity evidence because ATP-binding sites are conserved and off-target activity is chemotype-dependent. LRRK2 medicinal-chemistry programmes therefore use broad kinase profiling rather than assuming LRRK2 potency implies selectivity.

The default V0.5 panel is **literature-seeded surveillance**, not a universal LRRK2 safety panel:

```text
LRRK1
TTK
STK10
MAPK14
JNK2
CLK1
JNK3
DYRK2
SLK
DDR2
STK17B
```

The 2025 type-II LRRK2 work on RN341 used broad kinome screening and follow-up cellular validation for several of these kinases, and also assessed LRRK1. A 2026 macrocyclic LRRK2 programme explicitly optimised kinome selectivity in parallel with CNS and safety properties.

References:

- *Type II kinase inhibitors that target Parkinson's disease-associated LRRK2*, Science Advances (2025), `doi:10.1126/sciadv.ads3128`.
- *Discovery of Potent, Selective, CNS-Penetrant Macrocyclic LRRK2 Inhibitors for the Treatment of Parkinson's Disease*, Journal of Medicinal Chemistry (2026), `doi:10.1021/acs.jmedchem.6c00238`.

### 1. Resolve ChEMBL targets

V0.5 does **not** silently hard-code guessed target IDs. It resolves each name against live ChEMBL and only accepts a unique human `SINGLE PROTEIN` target. Ambiguity fails loudly.

```bash
pdl selectivity-resolve --target TTK
```

If a symbol is ambiguous, provide/record an explicit ChEMBL target ID after inspecting ChEMBL rather than accepting an arbitrary match.

### 2. Freeze the surveillance datasets

```bash
pdl selectivity-freeze \
  --targets LRRK1,TTK,STK10,MAPK14,JNK2,CLK1,JNK3,DYRK2,SLK,DDR2,STK17B \
  --out data/selectivity
```

Each target receives the same V0.3 ChEMBL provenance treatment: raw activity records, assay context, cleaned molecules and hashes.

### 3. Train what the data support

```bash
pdl selectivity-train \
  --input data/selectivity \
  --out artifacts/selectivity \
  --features 96
```

Targets with insufficient usable binary activity data are **skipped and reported**, not padded or hallucinated. Where sufficient data exist, the same scaffold-aware classical benchmark contract is used.

### 4. Annotate candidates

```bash
pdl selectivity-annotate \
  --input artifacts/lrrk2/candidates_medchem.csv \
  --models artifacts/selectivity \
  --out artifacts/lrrk2/candidates_selectivity.csv
```

Outputs include one probability per modelled off-target, the highest predicted off-target and a maximum off-target probability. If the LRRK2 `predicted_activity` column is present, the pipeline also reports a simple activity-probability margin proxy.

**That margin is not a biochemical selectivity ratio.** Probabilities from different target-specific classifiers are not directly equivalent to measured Ki/IC50 ratios. The field exists only for computational triage.

## Definition of done

V0.5 software is complete when:

- medicinal-chemistry evidence is reproducible and auditable;
- structural alerts are surfaced without being treated as automatic failure;
- novelty is defined against an explicit reference chemistry snapshot;
- target resolution fails on ambiguity rather than guessing;
- per-off-target ChEMBL datasets are frozen with provenance;
- insufficient off-target datasets are skipped transparently;
- candidate output preserves individual target probabilities;
- CI passes.

Scientific completion requires running the real ChEMBL selectivity panel and reviewing which targets have enough comparable data for useful models. Broad experimental kinome profiling remains the reference test for a serious lead programme.

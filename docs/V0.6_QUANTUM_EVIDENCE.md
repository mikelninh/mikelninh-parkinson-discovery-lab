# V0.6 — Quantum evidence, not a quantum headline

V0.6 upgrades the Rimay comparison from a single aggregate score to a **paired, molecule-level experiment**.

The project will not call Rimay useful because one ROC-AUC number happens to be larger. The comparison must preserve molecule identity and scaffold splits, quantify uncertainty in the performance delta, expose disagreement cases, repeat the experiment, and report the compute context.

## One frozen trial

Run Rimay on a frozen PDL dataset/split, then:

```bash
pdl quantum-trial \
  --prepared artifacts/lrrk2/dataset_prepared.csv \
  --classical-model artifacts/lrrk2/best_model.joblib \
  --rimay-result artifacts/rimay_seed42/result.csv \
  --out artifacts/quantum/seed42 \
  --backend-type simulator \
  --backend-name "Rimay Simulator" \
  --quantum-runtime-seconds 420 \
  --quantum-cost-eur 0
```

The trial:

- aligns by `molecule_id`, never row order;
- rejects missing molecules, duplicate IDs, altered labels and altered splits;
- evaluates the already-frozen classical best model on the same test molecules;
- if Rimay returns features, selects the downstream classifier on validation scaffolds and refits on train+validation;
- if Rimay returns probabilities, uses them directly;
- performs paired bootstrap resampling of the **same test molecules**;
- reports PR-AUC, ROC-AUC and Brier improvement confidence intervals;
- writes molecule-level classical/quantum probabilities and disagreement outcomes;
- records provider, simulator/QPU status, backend, runtime and cost when known.

## Trial decision

Primary metric: **PR-AUC**.

A single trial is labelled:

- `pass` only when the paired-bootstrap PR-AUC delta 95% CI is entirely above zero and the ROC-AUC point delta is non-negative;
- `fail` when the PR-AUC delta 95% CI is entirely at or below zero;
- `inconclusive` otherwise.

A single-trial `pass` is **not** a project-level quantum-advantage claim.

## Repeated scaffold trials

The final V0.6 decision requires at least three independent frozen scaffold trials. Five is the default target.

```bash
pdl quantum-meta \
  --trials \
    artifacts/quantum/seed11/trial.json \
    artifacts/quantum/seed23/trial.json \
    artifacts/quantum/seed42/trial.json \
    artifacts/quantum/seed71/trial.json \
    artifacts/quantum/seed101/trial.json \
  --out artifacts/quantum/meta_benchmark.json
```

The meta benchmark bootstraps the mean **trial-level PR-AUC delta** across scaffold trials.

Project-level result:

- `pass`: 95% CI for the mean PR-AUC delta is entirely > 0;
- `fail`: 95% CI is entirely <= 0;
- `inconclusive`: interval crosses zero;
- fewer than three trials: `inconclusive_insufficient_repeated_trials`.

## Disagreement analysis

`paired_test_predictions.csv` contains:

```text
molecule_id
active_label
classical_probability
quantum_probability
quantum_minus_classical_probability
absolute_probability_disagreement
classical_correct
quantum_correct
disagreement_outcome
```

Large disagreements are scientifically more interesting than a leaderboard alone. They tell us which chemistry the quantum-derived representation ranks differently and whether those differences are actually helpful on held-out scaffolds.

## Claim boundary

V0.6 distinguishes three claims:

1. **predictive gain** — Rimay features improved held-out predictive metrics;
2. **reproducible predictive gain** — that gain survived repeated scaffold trials;
3. **quantum computational advantage** — a much stronger claim requiring evidence that the useful computation cannot be reproduced competitively by classical alternatives, plus hardware/runtime/cost analysis.

The V0.6 software can establish the first two. It must **not automatically claim the third**.

Kipu's earlier Tinkuq forecast of +5–12 percentage points ROC-AUC remains a provider hypothesis until these experiments are run.

## Definition of done

V0.6 software is complete when:

- paired molecule-level trial evidence is generated;
- bootstrap confidence intervals are reported;
- disagreement cases are exported;
- simulator/QPU/runtime/cost metadata are recorded;
- fewer than three repeated trials cannot produce a project-level pass;
- repeated trials produce pass/fail/inconclusive under a declared rule;
- CI passes.

Scientific completion requires actual Rimay Simulator/QPU outputs on the frozen real LRRK2 benchmark. No quantum result is fabricated by the repository.
